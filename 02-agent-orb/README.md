# 微动效 Agent Orb

一个用 WebGL 点阵球表达 Agent 状态的交互示例。微动效与状态文字同步变化。

| 状态 | 画面反馈 |
| --- | --- |
| 待命 · Standby | 点阵球收起，显示虹膜图形 |
| 思考 · Thinking | 点阵地球旋转 |
| 构建 · Building | 点阵旋转，叠加周期波纹 |
| 生成 · Generating | 点阵旋转加快，叠加扫描波 |
| 等待 · Waiting | 球体减速，外圈脉冲提示轮到用户 |
| 报错 · Error | 球体泛红并短促抖动 |

- [index.html](index.html) 定义状态按钮、状态文字、动画过渡和着色器。WebGL 先绘制球壳、光圈与虹膜，再叠加点阵。
- [particles.js](particles.js) 用斐波那契球面分布生成 1,300 个点，并用 144 × 72 的一位陆地掩码给每个点标记陆地或海洋。

切换时，状态权重和转速随帧间时间平滑过渡。页面通过 `aria-live` 播报状态文字，并在系统开启「减少动态效果」时停掉持续动画。
