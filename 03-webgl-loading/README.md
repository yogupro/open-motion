# 导出光带 · 完整学习资料包

感谢关注。这个资料包是第三期视频里拆开的那条导出加载，双击就能在浏览器里再看一遍。

## 文件清单

1. **`index.html`**
   - 460 行，零第三方依赖。HTML、CSS、WebGL 着色器和粒子画在同一个文件里。
   - 用 Chrome、Edge 或 Safari 直接打开。页面会在 1.4 秒后自动播放一次。
   - 建议看这几个瞬间：
     - 暖光先停在对话框底部，五团光斑慢慢变形；
     - 状态从「正在整理文件…」换成「正在生成压缩包…」；
     - 最后半秒光带上抬，文字从页脚往上变清晰，文件名变成绿色；
     - 点「再看一次」重放。按 `Esc` 可以关掉对话框。
2. **`导出光带-微交互原理速查手册.md`**
   - 时间轴、五团椭圆高斯、纸面减色着色器、拖尾和逐行去模糊
   - WebGL 不可用时的 CSS 径向渐变兜底
   - 8 条可以直接拿去改自己加载态的检查清单

系统打开「减少动态效果」时，光带和模糊会停掉，对话框直接切到完成态。
