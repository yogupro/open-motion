# 导出光带（460 行零依赖）微交互原理速查手册

> 配套源码：同目录下的 `index.html`。零第三方依赖，双击用浏览器打开，1.4 秒后自动播放。

对话框尺寸 `456×474px`，圆角 `32px`。加载大约 4.94 秒。画面里没有进度条，也没有 GIF。底部一道暖光先变形，再在最后半秒整条抬走，文字跟着从页脚往上变清晰。

---

## 一、画面是怎么叠起来的

| 层 | 谁负责 | 做什么 |
| --- | --- | --- |
| 背景 | `.library` | 静态文件库。`pointer-events: none`，只负责被压暗 |
| 压暗 | `.scrim` | 整屏渐变遮罩 |
| 对话框内容 | 标题、文件名、四行明细、按钮 | 普通 DOM。清晰度由每一块自己的 `filter` / `opacity` 决定 |
| 状态胶囊 | `.status` | CSS 锥形渐变小环 + 文字流光。文案在 2.44 秒从「正在整理文件…」换成「正在生成压缩包…」 |
| 暖光 | `<canvas class="field">` | WebGL 五团椭圆高斯。画布被对话框圆角裁切 |
| 尘埃 | `<canvas class="particles">` | 146 颗 2D 粒子，跟着光带的局部高度往上飘 |

舞台用 `--stage-scale` 和 `--dialog-scale` 适配窗口。对话框最小可读宽度按 `320 / 456` 兜住，避免缩得连「项目素材.zip」都看不清。

## 二、五秒时间轴

播放时钟是 `startExport()` 里的 `performance.now()`。着色器内部再用 `time = elapsed + 1.4`，把采样对齐到参考录像。

| 经过时间 | 画面 |
| --- | --- |
| 0–0.68s | 内容整体进入模糊。模糊系数从 0 到 1，最大 8px |
| 0.34–0.47s | 暖光 `gain` 在 130ms 内淡入 |
| 0.45–0.83s | 状态胶囊淡入 |
| 0.43–4.03s | 25 帧光斑关键帧逐帧插值。此时抬升量仍是 0，光停在底部 |
| 2.44s | 文案切到「正在生成压缩包…」 |
| 4.03–4.67s | 光带按 11 个采样从 0 抬到 1.44 倍画布高度，冲出顶边 |
| 4.07s | 切到完成态：标题「导出完成」，文件名变 `#15963d` |
| 4.09–4.93s | 模糊从页脚往上退掉 |
| 4.16–4.49s | 状态胶囊淡出 |
| 4.94s | 停掉光带和粒子，留下清晰的完成对话框 |

关键帧下标是 `(time - 1.83) / 0.15`。25 组采样、每组 5 个数，组与组之间 150ms，中间用小数部分线性混合。

## 三、五个核心做法

### 1. 五团椭圆高斯，不贴一张渐变图

每团光是一个椭圆高斯：

```text
lobe = strength * exp(-0.5 * dot(q, q))
q = (p - center) / spread
```

五团按着色器里的名字是 yellow、coral、lilac、orchid、rose。每帧 25 个数，顺序是每团的 `cx, cy, sx, sy, power`。运动中还会把中心和横向半径乘上 `horizontalScale`，光带上抬时两侧往中间收，最多大约收掉 26%。

### 2. 纸面减色，不叠霓虹

片元着色器不把彩色光直接加到白底上。它先用五团权重算出绿色亏损和蓝色亏损，再做成偏暖的负向 `tint`，最后写进接近白纸的底色：

```text
ink = 0.984 + 0.012 * noise + tint / density
alpha = density * gain
```

`0.012` 的哈希噪声打在像素网格上，用来打断 8-bit 渐变色带。桃色散景（peach）单独加在黄色核心上方，比黄核更宽、更靠上。

没有 WebGL 时，同一组椭圆退成五层 CSS `radial-gradient`。兜底色是 `255,195,52`、`255,112,102`、`238,87,254`、`229,66,248`、`245,119,174`。几何还是那五个椭圆，只是不再做纸面减色。

### 3. 拖尾只在抬升时出现

抬升曲线 `sweep` 有 11 个点，着色器时间 5.43 到 6.07，也就是播放后 4.03 到 4.67 秒。在这之前 `lift` 被钳在 0，所以前四秒只有形变，没有上飘。

抬起来之后有两笔拖尾：

- **中心滞后**：`lift - sweepAt(time - 0.017)`，中间比两侧多落后约 17ms。
- **下沿拉长**：只拉伸光核下半边，拉伸量 `0.95 * ease((lift - 0.23) / 0.74)`。

所以上升的光带中间凹一点、底下拖一条，不是一块矩形色块在平移。

### 4. 文字清晰度跟光带高度走

每个内容块有一个高度锚点：

| 块 | 锚点 y |
| --- | --- |
| 按钮区 | 0.09 |
| 四行明细 | 0.54、0.44、0.34、0.24 |
| 明细底板 | 0.52 |
| 文件名 | 0.68 |
| 标题 | 0.91 |

去模糊波从 `-0.14` 走到 `1.29`。某一块的模糊在波前经过 `y + 0.33` 后归零。y 小的先清楚，所以是页脚先锐、标题后锐。透明度同步为 `1 - 0.64 * blur`。

### 5. 146 颗尘埃，种子写死

粒子用线性同余，种子 `17513`，所以每次播放的起点一致。每颗有自己的寿命、上升速度、半径和左右漂移。可见度从播放后约 0.92 秒淡入，约 4.46 秒淡出。y 坐标减去当前的局部抬升，尘埃会贴着光带一起走。

`prefers-reduced-motion: reduce` 时不画光带、不加模糊，CSS 动画时长归零。WebGL context 丢失后会丢掉 program，恢复时重新编译。

## 四、8 条加载态检查清单

| # | 维度 | 推荐做法 | 避免的坑 |
| --- | --- | --- | --- |
| 1 | **光从哪来** | 用少量椭圆高斯实时算，关键帧 150ms 一档 | 用 GIF 或整张渐变图，改颜色就要重导出 |
| 2 | **颜色模型** | 在纸白上减绿、减蓝，让光看起来嵌在界面里 | 高饱和色直接 `lighter` 叠上去，像一层滤镜 |
| 3 | **节奏** | 长时间只变形，完成前再抬走 | 光带从头循环扫，完成瞬间没有收束 |
| 4 | **拖尾** | 中心滞后 + 只拉下沿，而且只在抬升段启用 | 整块色带平移，边缘一样齐 |
| 5 | **文字** | 按行高锚点，让模糊跟着光走 | 整张卡片一起 `opacity`，读不到「正在发生」 |
| 6 | **粒子** | 固定种子，数量和寿命写死，方便对帧 | 每帧 `Math.random()`，录屏和实机对不上 |
| 7 | **降级** | 同一组椭圆参数驱动 CSS 径向渐变；响应 `prefers-reduced-motion` | WebGL 失败就黑一块，或对前庭敏感的用户被迫看扫光 |
| 8 | **收尾** | 光走完再卸掉 canvas，完成态用颜色和图标单独交代 | 加载层和完成态叠在一起，或完成后光还在循环 |
