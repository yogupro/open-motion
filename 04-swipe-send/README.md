# 上滑转账 · 完整学习资料包

感谢关注。这个资料包是第四期视频里拆开的上滑确认转账，用浏览器打开就能再滑一次。

## 文件清单

1. **`index.html`** 和同目录的 `motion.js`、`renderer.js`、`receipt.js`、`screen.css`、`receipt.css`、`lin-yue.png`
   - 零第三方依赖。没有构建步骤。
   - 用 Chrome、Edge 或 Safari 直接打开 `index.html`。
   - 建议看这几个瞬间：
     - 按住底部按钮上滑。后半段同样的手指距离，按钮抬得更少；
     - 没过线就松手，按钮弹回去，提示仍是「继续上滑」；
     - 过线之后按钮咬住，提示变成「松手确认转账」，松手才发送；
     - 发送时底部升起一道光箭，「正在向林悦转账」从左往右写出来；
     - 回执前半秒被一道环拉开颜色，然后换成可以点的界面，勾从浅紫变成薄荷色。
   - 也可以打开 `index.html?preview`，页面会自己播一遍。键盘 `↑` 或回车同样能确认。
2. **`上滑转账-微交互原理速查手册.md`**
   - 阻力曲线、过线回差、回弹、光箭和折射回执
   - 8 条可以直接拿去改自己确认手势的检查清单

系统打开「减少动态效果」时，上滑会直接进入完成态，不再飞光箭，也不再做折射。
